# 对话中的任务

对话里的任务记录与聊天回复分开保存。任务执行状态不等于代码已合并或应用已发布。

## 查看任务

Web 对话顶部的“任务”打开当前对话的任务记录，包含已完成和无法关联到消息的任务。入口显示进行中与当前待处理数量。离线或同步未完成时，列表说明当前只显示最近或已读取的记录。

点击记录进入任务详情，关闭详情后回到对话。任务详情保留执行设备、执行程序、结果及相关操作。

## 阅读对话

Web 中的任务跟随发起它的消息，Bot 回复到达后也不移动。同一次请求产生的多个任务合并展示，可展开查看。完成后只保留“已完成 · 查看任务”，不在消息区重复标题、设备和结果摘要。无法关联到当前消息的历史任务只在任务记录中展示，不追加到输入框上方。

待审批和结果待确认的事项保持可见、可操作。结果未知不按完成处理，也不自动重发。
