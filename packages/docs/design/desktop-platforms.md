# macOS、Windows 桌面与 Windows 本机运行

本次实现提供 Electron 桌面宿主，复用 React 业务界面，并补齐原生 Windows Rust Core/CLI。用户指定 Grok Bot 为参考；本机 0.79.2 安装包包含 Electron Framework 与 app.asar。本轮目标是完整实现、验证并提交一个 PR，合并与发布另行按授权执行。

桌面负责窗口、单实例、菜单/托盘、系统交互、启动与离线引导。Core 继续负责持久化、同步、调度与 Provider，CLI 继续负责管理。桌面已有实例与自行启动的实例必须区分所有权；退出不停止已有服务，不自动复制浏览器身份或迁移数据。

Windows 移植包含当前用户隔离的私有 IPC、文件权限、数据锁、进程树、命令/路径、用户级服务以及更新与恢复。正常功能不能用空实现或整块 cfg 排除替代。网络或执行结果未知时保留原工作身份并核对，不能重放写操作。

Mac 桌面、Windows 桌面和 Windows Core/CLI 纳入统一产品版本及并行构建。数据 epoch、更新协议保持 1，正式版前保持 0.0.1 Nightly。验证覆盖真实平台进程、窗口与制品，使用受控 Provider 夹具。

实现按 Windows 运行时、桌面宿主、构建与交付三个边界分工；主 Agent 负责接口、集成与最终验收。具体模块接口和最终检查结果随实现补齐。
