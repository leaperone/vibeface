# 移动端聊天栏

聊天记录延伸到顶部导航和底部输入区后方。借鉴 Codync iOS 的轻量导航和悬浮输入区，保留 Vibeface 原有发送、停止、附件与离线状态。

- 顶部保留系统返回手势和 Bot 信息入口，避免通栏厚重底色。
- 输入区使用圆角半透明材质，单行草稿占用一行，长草稿按内容增长。
- 聊天列表可以滚到栏位下方，最新消息停在输入框上方。
- 键盘展开、交互式收起和回到底部继续由现有键盘控制器处理。
- 明暗主题都保持文字对比度。减少透明度时使用实色背景。
- 仅调整原生手机聊天页，不改变消息、授权或同步协议。

验收覆盖长历史、输入增长、发送与停止、键盘开合、回到底部和明暗主题。源码检查不能替代 iOS 渲染验收。
