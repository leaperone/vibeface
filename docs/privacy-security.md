# 谁能读到内容，权限在哪里生效

Vibeface 用独立设备密钥和签名授权管理个人网络，并验证与加密连接。运行任务的 Node 和所选模型服务仍会处理任务内容；授权设备、网页来源与宿主机都需要你信任。

## 身份与加入批准

建立个人网络不需要注册 Vibeface 中心账号。网络有自己的根身份，Node、浏览器与手机各用独立日常设备密钥。密钥证明设备身份，不代表匿名访问，也不能代替模型服务要求的账号。

新设备通过加入链接申请，管理设备核对安全码后签署批准。当前成员权限区分设备类型和是否能管理成员，没有团队空间或会话级细粒度 ACL。只把你信任、愿意让它接触个人网络内容的设备加入网络。步骤见 [添加自己的设备](node.md#添加自己的设备)。

本机短期访问与永久成员身份不同。可信本机会话可管理本机业务和配置，不能代替管理客户端签署成员授权，详见 [本机自动访问](node.md#本机自动访问)。

## 内容经过哪些位置

客户端钉住目标 Node 身份，并建立 Noise 加密通道。Node 之间的连接也认证设备身份并加密。目标 Node 解密业务后，继续检查个人网络成员权限。

各个位置能接触的数据不同：

| 位置 | 能接触什么 |
| --- | --- |
| 可信浏览器或手机客户端 | 你查看和输入的聊天、结果与附件。网页来源必须可信。 |
| 只负责转发的公共入口 | 转发密文，不因转发成为个人网络成员；仍可观察目标编号与流量信息。 |
| 已授权的成员 Node | 解密并保存该个人网络的业务记录，按配置协调或执行任务。 |
| 所选 Agent 与模型服务 | 执行所需的提示、文件或工具结果，具体数据处理政策由该产品和服务决定。 |

本机运行 Agent 不代表本机离线推理。Vibeface 不能替外部模型服务承诺请求保留政策。

网页 HTTP 入口默认监听回环地址，Node 间 iroh UDP 传输默认绑定全接口，两者不是同一个入口。公网反向代理、监听与防火墙配置见 [配置网络入口](deployment.md#配置网络入口)。

## 凭证与本机数据

配置的 Provider 环境变量保存在本机私有的 `provider-env.json`，不进入共享 Bot 设置和 DAG。每台需要运行该产品的设备分别准备登录或凭证。

你主动发送的签名消息和附件仍作为正文同步。不要把密钥、恢复密码或其他秘密发进聊天，也不要假设它们会被自动清除。

传输加密不等于 Node 磁盘静态加密。Node 的 SQLite 保存事件正文，附件也保存在本机。设备私钥、Provider 配置、SDK 会话和完整数据备份都含敏感信息，应使用可信系统用户、磁盘保护和备份存储。

## 执行权限与项目目录

新任务的真实目录必须通过执行 Node 的 `roots` 检查。Bot 的项目偏好本身不授予路径权限。这个检查只覆盖新任务的目录选择，不构成操作系统沙箱，也不约束 Agent 对宿主机的全部访问。

协调 Agent 的 Shell 和文件工具可以访问宿主机。Codex 使用 `danger-full-access`，Claude Code 使用 `bypassPermissions`，它们可以读写文件和运行命令。对已有原生会话的续接也有自己的目录规则。Node 工具令牌对网络和聊天的限制，不会把这些宿主工具变成只读工具。

只在你愿意交给 Agent 操作的系统用户和设备上启用它。具体接入和工作登记规则见 [Bot 与任务执行](bot-and-execution.md) 及 [Node 使用文档](node.md#创建机器人并处理结果)。

## 撤销与恢复

管理设备可以撤销成员。端点收到签名撤销记录后拒绝该成员后续操作，离线分区要等收到记录才生效。撤销不能收回已经读到的明文，也不保证停止已经运行的外部进程。

加密恢复包包含恢复签名身份与成员授权记录，用于找回管理权。它不备份聊天、工程、SDK 会话或模型凭证。密码只保护恢复材料，不是 Node 的连接密码。

用恢复文件更换成员目录、找回管理权时，先保存新的恢复文件，再提交恢复。当前有 48 小时等待期，原目录中的有效管理设备可以否决。等待期内签署的有效否决即使迟到，也可能让副本返回原目录；仍有效的被盗管理设备可能阻止找回。只轮换恢复密钥的操作立即生效，与更换成员目录的找回不同。

恢复身份不会补出已经丢失的业务正文。仍需可达的授权副本或独立备份，详见 [历史同步与备份](history-sync.md#同步与备份各自负责什么)、[备份与恢复](node.md#备份与恢复) 和 [恢复排障](troubleshooting.md#常见问题)。
